# CineApp - Catálogo de películas (Flutter)

## Cómo correrlo

1. Descomprime la carpeta y ábrela en una terminal.
2. Genera las carpetas de plataforma (android, ios, etc.):

       flutter create .

3. Instala dependencias y corre:

       flutter pub get
       flutter run

Si `flutter create .` genera `test/widget_test.dart`, bórralo (hace referencia a `MyApp`).
Requiere Flutter 3.22 o superior.
